MetalTask

See which processes are using the GPU on your Apple Silicon Mac and how much graphics memory macOS attributes to them.

Install Source on GitHub

Install with Homebrew

brew install digital-defiance/tap/metaltask
metaltask

The formula builds from source. Select Xcode with Swift 6 first. MetalTask targets macOS 14 and has been tested on an M4 Max running macOS 26.

Monitor and compare workloads

See five minutes of device activity and sort GPU processes by activity or graphics footprint. Export local JSON snapshots and compare the readings before and after a workload change.

metaltask --snapshot-json > before.json
metaltask --snapshot-json > after.json
metaltask --compare before.json after.json

Inspect model metadata

Check an existing local Ollama service or select a GGUF file in Loaded Models. Ollama is optional.
